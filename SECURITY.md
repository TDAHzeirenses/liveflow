# Segurança

## Reportar vulnerabilidade

Envie um relato privado para o canal de suporte indicado em [`SUPPORT.md`](SUPPORT.md), com descrição do impacto e passos mínimos de reprodução. Não publique exploit, tokens, dados de canal, bancos ou logs que identifiquem contas.

O projeto não oferece atualmente uma política de recompensa ou SLA de resposta. Não há promessa de prazo de correção.

## Limites

O código público contém apenas o motor de recorrência MPL-2.0. Relatos que envolvam o núcleo proprietário serão triados pelo publicador; não tente obter ou contornar credenciais. A aplicação não deve registrar senha Google, código de autorização, access token, refresh token ou Client Secret.
