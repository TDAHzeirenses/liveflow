# Código de Conduta

Este projeto recebe contribuições com respeito e boa-fé. Esperamos comunicação clara, cordial e inclusiva, foco no mérito técnico e cuidado para não publicar dados privados ou credenciais.

Não são aceitos assédio, insultos, discriminação, ameaças, doxxing, publicação de informações pessoais ou tentativa de obter acesso não autorizado. O responsável pelo projeto pode moderar conteúdo que viole estas regras e encaminhar relatos ao contato de suporte.

Para relatar uma situação, use o contato publicado em [`SUPPORT.md`](SUPPORT.md). Inclua somente as informações necessárias e nunca envie senhas ou tokens.
