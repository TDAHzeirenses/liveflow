# Contributing

Contributions to the published Open Core module are welcome under the Mozilla Public License 2.0.

1. Keep changes within the files listed in the Open Core license map.
2. Add or update focused tests under `open_core/tests/`.
3. Run `python -m unittest discover -s open_core/tests -v` before submitting a change.
4. Do not include credentials, tokens, user databases, payment data, private application source, or generated executables.

Submitting a contribution does not grant rights to the LiveFlow brand or components that are not included in this repository.
